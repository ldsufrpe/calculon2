    Subseção 1.1 Multiplicadores de Lagrange com uma Restrição

    Suponha que desejamos determinar os valores máximos ou mínimos de uma função diferenciável de duas variáveis \(f(x, y)\) cujos pontos \((x, y)\) estão restritos a pertencer a uma curva de nível suave de outra função, dada por \(g(x, y) = k\text{.}\) Ou seja, queremos otimizar \(f(x, y)\) sujeita à restrição \(g(x, y) = k\text{.}\)
    🔗
    Geometricamente, a Figura 1.2 ilustra a curva de restrição \(g(x, y) = k\) juntamente com diversas curvas de nível da função objetivo \(f(x, y) = c\) para diferentes valores de \(c\text{.}\) Para maximizar \(f(x, y)\) sob a restrição, procuramos o maior valor possível de \(c\) tal que a curva de nível correspondente intercepte a curva de restrição.
    🔗
    Note na figura que esse valor de máximo ocorre precisamente quando a curva de nível de \(f\) é tangente à curva de restrição \(g(x, y) = k\text{.}\) Se elas se cruzassem transversalmente, poderíamos nos mover ao longo da restrição para alcançar uma curva de nível com valor de \(c\) ainda maior. No ponto de tangência \(P_0(x_0, y_0)\text{,}\) a reta tangente à curva de nível de \(f\) e a reta tangente à curva de restrição coincidem. Consequentemente, as direções normais a essas curvas no ponto também devem coincidir. Como os vetores gradientes \(\nabla f(x_0, y_0)\) e \(\nabla g(x_0, y_0)\) são normais às suas respectivas curvas de nível, concluímos que eles devem ser paralelos. Algebricamente, isto significa que:
    🔗
    \begin{equation*} \nabla f(x_0, y_0) = \lambda \nabla g(x_0, y_0) \end{equation*}
    para algum escalar constante \(\lambda\text{,}\) que é chamado de multiplicador de Lagrange.
    🔗

    O Método dos Multiplicadores de Lagrange (Uma Restrição).

    Suponha que \(f\) e \(g\) sejam funções diferenciáveis com \(\nabla g \neq \mathbf{0}\) sobre a curva ou superfície de restrição \(g = k\text{.}\) Para determinar os valores de máximo e mínimo de \(f\) sujeitos à restrição \(g = k\text{:}\)
    🔗
    🔗
    Alternativamente (conforme apresentado por Ron Larson), podemos introduzir a função auxiliar Lagrangiana \(F\) definida por:
    🔗
    • Para duas variáveis, \(f(x, y)\) sujeita a \(g(x, y) = k\text{:}\)
      🔗
      \begin{equation*} F(x, y, \lambda) = f(x, y) - \lambda \left(g(x, y) - k\right) \end{equation*}
      Para encontrar os pontos críticos de \(F\text{,}\) igualamos a zero suas derivadas parciais de primeira ordem em relação a todas as variáveis:
      🔗
      \begin{align*} F_x(x, y, \lambda) \amp = f_x(x, y) - \lambda g_x(x, y) = 0 \implies f_x = \lambda g_x\\ F_y(x, y, \lambda) \amp = f_y(x, y) - \lambda g_y(x, y) = 0 \implies f_y = \lambda g_y\\ F_\lambda(x, y, \lambda) \amp = -\left(g(x, y) - k\right) = 0 \implies g(x, y) = k \end{align*}
      Observe que este procedimento gera exatamente o mesmo sistema de equações (1.1).
      🔗
      🔗
    • Para três variáveis, \(f(x, y, z)\) sujeita a \(g(x, y, z) = k\text{:}\)
      🔗
      \begin{equation*} F(x, y, z, \lambda) = f(x, y, z) - \lambda \left(g(x, y, z) - k\right) \end{equation*}
      Para encontrar os pontos críticos de \(F\text{,}\) igualamos a zero suas derivadas parciais de primeira ordem em relação a todas as variáveis:
      🔗
      \begin{align*} F_x(x, y, z, \lambda) \amp = f_x(x, y, z) - \lambda g_x(x, y, z) = 0 \implies f_x = \lambda g_x\\ F_y(x, y, z, \lambda) \amp = f_y(x, y, z) - \lambda g_y(x, y, z) = 0 \implies f_y = \lambda g_y\\ F_z(x, y, z, \lambda) \amp = f_z(x, y, z) - \lambda g_z(x, y, z) = 0 \implies f_z = \lambda g_z\\ F_\lambda(x, y, z, \lambda) \amp = -\left(g(x, y, z) - k\right) = 0 \implies g(x, y, z) = k \end{align*}
      Observe que este procedimento gera exatamente o mesmo sistema de equações (1.4).
      🔗
      🔗

    Exemplo 1.3. Volume Máximo de Sólido Retangular.

    Determine o volume máximo de uma caixa retangular (sólido) no primeiro octante com faces paralelas aos planos coordenados, sabendo que o vértice oposto à origem está situado sobre o plano \(6x + 4y + 3z = 24\text{.}\)
    🔗
    Solução.
    O volume da caixa com dimensões \(x\text{,}\) \(y\) e \(z\) é a nossa função objetivo:
    🔗
    \begin{equation*} f(x, y, z) = xyz \end{equation*}
    O ponto \((x, y, z)\) está restrito a pertencer ao plano no primeiro octante (\(x > 0, y > 0, z > 0\)). A restrição é dada por:
    🔗
    \begin{equation*} g(x, y, z) = 6x + 4y + 3z = 24 \end{equation*}
    Definimos a função Lagrangiana:
    🔗
    \begin{equation*} F(x, y, z, \lambda) = xyz - \lambda(6x + 4y + 3z - 24) \end{equation*}
    Calculando as derivadas parciais de \(F\) e igualando-as a zero, obtemos o sistema:
    🔗
    \begin{align*} F_x \amp = yz - 6\lambda = 0 \implies \lambda = \frac{yz}{6}\\ F_y \amp = xz - 4\lambda = 0 \implies \lambda = \frac{xz}{4}\\ F_z \amp = xy - 3\lambda = 0 \implies \lambda = \frac{xy}{3}\\ F_\lambda \amp = -(6x + 4y + 3z - 24) = 0 \implies 6x + 4y + 3z = 24 \end{align*}
    Igualando as expressões para \(\lambda\) das duas primeiras equações (com \(z \neq 0\text{,}\) pois queremos volume máximo):
    🔗
    \begin{equation*} \frac{yz}{6} = \frac{xz}{4} \implies 4y = 6x \implies y = \frac{3}{2}x \end{equation*}
    Igualando a primeira com a terceira equação (com \(y \neq 0\)):
    🔗
    \begin{equation*} \frac{yz}{6} = \frac{xy}{3} \implies 3z = 6x \implies z = 2x \end{equation*}
    Agora, substituímos essas relações na equação de restrição:
    🔗
    \begin{equation*} 6x + 4\left(\frac{3}{2}x\right) + 3\left(2x\right) = 24 \end{equation*}
    \begin{equation*} 6x + 6x + 6x = 24 \implies 18x = 24 \implies x = \frac{4}{3} \end{equation*}
    Substituindo de volta para obter as outras dimensões e o multiplicador de Lagrange:
    🔗
    \begin{equation*} y = \frac{3}{2}\left(\frac{4}{3}\right) = 2 \end{equation*}
    \begin{equation*} z = 2\left(\frac{4}{3}\right) = \frac{8}{3} \end{equation*}
    Portanto, as dimensões ótimas são \(x = 4/3\text{,}\) \(y = 2\) e \(z = 8/3\text{.}\) O volume máximo é:
    🔗
    \begin{equation*} f\left(\frac{4}{3}, 2, \frac{8}{3}\right) = \left(\frac{4}{3}\right)(2)\left(\frac{8}{3}\right) = \frac{64}{9} \approx 7,11 \text{ unidades cúbicas.} \end{equation*}
    🔗
    🔗

    Exemplo 1.5. Otimização de Produção (Modelo Cobb-Douglas).

    A produção de uma fabricante é modelada pela função de Cobb-Douglas \(f(x, y) = 100 x^{3/4} y^{1/4}\text{,}\) onde \(x\) representa as unidades de mão de obra e \(y\) as unidades de capital. Cada unidade de mão de obra custa $150 e cada unidade de capital custa $250. O orçamento total da fábrica é de $50.000. Determine a quantidade ideal de insumos de mão de obra e capital para maximizar a produção.
    🔗
    Solução.
    A nossa função objetivo (produção) é \(f(x, y) = 100 x^{3/4} y^{1/4}\text{.}\) O custo total não pode exceder $50.000. Uma vez que queremos maximizar a produção, utilizaremos todo o orçamento. Assim, a restrição de custo é:
    🔗
    \begin{equation*} 150x + 250y = 50.000 \implies g(x, y) = 150x + 250y - 50.000 = 0 \end{equation*}
    Montamos a Lagrangiana:
    🔗
    \begin{equation*} F(x, y, \lambda) = 100 x^{3/4} y^{1/4} - \lambda(150x + 250y - 50.000) \end{equation*}
    Derivando parcialmente em relação a \(x\text{,}\) \(y\) e \(\lambda\) e igualando a zero:
    🔗
    \begin{align*} F_x \amp = 75 x^{-1/4} y^{1/4} - 150\lambda = 0 \implies \lambda = \frac{75 y^{1/4}}{150 x^{1/4}} = \frac{1}{2}\left(\frac{y}{x}\right)^{1/4}\\ F_y \amp = 25 x^{3/4} y^{-3/4} - 250\lambda = 0 \implies \lambda = \frac{25 x^{3/4}}{250 y^{3/4}} = \frac{1}{10}\left(\frac{x}{y}\right)^{3/4}\\ F_\lambda \amp = -(150x + 250y - 50.000) = 0 \implies 150x + 250y = 50.000 \end{align*}
    Igualando as duas expressões obtidas para \(\lambda\text{:}\)
    🔗
    \begin{equation*} \frac{1}{2}\left(\frac{y}{x}\right)^{1/4} = \frac{1}{10}\left(\frac{x}{y}\right)^{3/4} \end{equation*}
    Multiplicamos ambos os lados por \(10 \cdot x^{1/4} y^{3/4}\) para simplificar os expoentes fracionários:
    🔗
    \begin{equation*} 5 \left(\frac{y}{x}\right)^{1/4} x^{1/4} y^{3/4} = \left(\frac{x}{y}\right)^{3/4} x^{1/4} y^{3/4} \end{equation*}
    \begin{equation*} 5 y = x \end{equation*}
    Substituímos \(x = 5y\) na equação de restrição orçamentária:
    🔗
    \begin{equation*} 150(5y) + 250y = 50.000 \end{equation*}
    \begin{equation*} 750y + 250y = 50.000 \implies 1.000y = 50.000 \implies y = 50 \end{equation*}
    Determinamos \(x\) a partir de \(y\text{:}\)
    🔗
    \begin{equation*} x = 5(50) = 250 \end{equation*}
    Portanto, a combinação ótima de insumos é de 250 unidades de mão de obra e 50 unidades de capital. O nível de produção máximo alcançado sob essa restrição é:
    🔗
    \begin{equation*} f(250, 50) = 100(250)^{3/4}(50)^{1/4} \approx 16.719 \text{ unidades.} \end{equation*}
    🔗
    🔗

    Subseção 1.2 Multiplicadores de Lagrange com duas Restrições

    Suponha agora que queiramos otimizar uma função de três variáveis \(f(x, y, z)\) sujeita a duas restrições da forma \(g(x, y, z) = k\) e \(h(x, y, z) = c\text{.}\) Supondo que as superfícies de restrição se interceptem em uma curva suave \(C\text{,}\) queremos determinar os extremos de \(f\) sobre esta curva de interseção.
    🔗
    Geometricamente, para que \(f\) tenha um valor extremo em um ponto \(P_0\) sobre a curva \(C\text{,}\) a superfície de nível de \(f\) passando por \(P_0\) deve ser tangente à curva \(C\text{.}\) Consequentemente, o vetor gradiente \(\nabla f(P_0)\) deve ser ortogonal à direção tangente de \(C\text{.}\) Como os gradientes \(\nabla g(P_0)\) e \(\nabla h(P_0)\) também são ortogonais a \(C\text{,}\) conclui-se que \(\nabla f(P_0)\) deve estar contido no plano gerado por \(\nabla g(P_0)\) e \(\nabla h(P_0)\text{.}\) Isto é, \(\nabla f\) deve ser uma combinação linear de \(\nabla g\) e \(\nabla h\text{:}\)
    🔗
    \begin{equation*} \nabla f(x, y, z) = \lambda \nabla g(x, y, z) + \mu \nabla h(x, y, z) \end{equation*}
    onde \(\lambda\) e \(\mu\) são dois multiplicadores de Lagrange escalares independentes.
    🔗

    O Método dos Multiplicadores de Lagrange (Duas Restrições).

    Para determinar os valores extremos de uma função diferenciável \(f(x, y, z)\) sujeita às restrições \(g(x, y, z) = k\) e \(h(x, y, z) = c\text{:}\)
    🔗
    🔗
    De forma equivalente (estendendo a formulação de Ron Larson), podemos introduzir a função auxiliar Lagrangiana com dois multiplicadores de Lagrange, \(F(x, y, z, \lambda, \mu)\text{,}\) definida por:
    🔗
    \begin{equation*} F(x, y, z, \lambda, \mu) = f(x, y, z) - \lambda \left(g(x, y, z) - k\right) - \mu \left(h(x, y, z) - c\right) \end{equation*}
    Para encontrar os pontos críticos de \(F\text{,}\) igualamos a zero suas derivadas parciais de primeira ordem em relação a todas as variáveis:
    🔗
    \begin{align*} F_x(x, y, z, \lambda, \mu) \amp = f_x(x, y, z) - \lambda g_x(x, y, z) - \mu h_x(x, y, z) = 0 \implies f_x = \lambda g_x + \mu h_x\\ F_y(x, y, z, \lambda, \mu) \amp = f_y(x, y, z) - \lambda g_y(x, y, z) - \mu h_y(x, y, z) = 0 \implies f_y = \lambda g_y + \mu h_y\\ F_z(x, y, z, \lambda, \mu) \amp = f_z(x, y, z) - \lambda g_z(x, y, z) - \mu h_z(x, y, z) = 0 \implies f_z = \lambda g_z + \mu h_z\\ F_\lambda(x, y, z, \lambda, \mu) \amp = -\left(g(x, y, z) - k\right) = 0 \implies g(x, y, z) = k\\ F_\mu(x, y, z, \lambda, \mu) \amp = -\left(h(x, y, z) - c\right) = 0 \implies h(x, y, z) = c \end{align*}
    Observe que este procedimento gera exatamente o mesmo sistema de equações (1.8).
    🔗

    Exemplo 1.7. Extremos sobre uma Curva de Interseção.

    Determine os valores máximo e mínimo da função \(f(x, y, z) = x + 2y + 3z\) sobre a curva de interseção do plano \(x - y + z = 1\) com o cilindro \(x^2 + y^2 = 1\text{.}\)
    🔗
    Solução.
    Neste problema, temos a função objetivo \(f(x, y, z) = x + 2y + 3z\) sujeita às restrições:
    🔗
    \begin{equation*} g(x, y, z) = x - y + z = 1 \quad \text{e} \quad h(x, y, z) = x^2 + y^2 = 1 \end{equation*}
    Calculando os vetores gradientes de cada função:
    🔗
    \begin{equation*} \nabla f = \langle 1, 2, 3 \rangle, \quad \nabla g = \langle 1, -1, 1 \rangle, \quad \nabla h = \langle 2x, 2y, 0 \rangle \end{equation*}
    O sistema de equações de Lagrange \(\nabla f = \lambda \nabla g + \mu \nabla h\) junto com as restrições é dado por:
    🔗
    \begin{align*} 1 \amp = \lambda + 2\mu x \quad \text{(Equação 1)}\\ 2 \amp = -\lambda + 2\mu y \quad \text{(Equação 2)}\\ 3 \amp = \lambda \quad \text{(Equação 3)}\\ x - y + z \amp = 1 \quad \text{(Equação 4)}\\ x^2 + y^2 \amp = 1 \quad \text{(Equação 5)} \end{align*}
    Substituindo \(\lambda = 3\) (da Equação 3) nas Equações 1 e 2:
    🔗
    \begin{equation*} 1 = 3 + 2\mu x \implies 2\mu x = -2 \implies \mu x = -1 \end{equation*}
    \begin{equation*} 2 = -3 + 2\mu y \implies 2\mu y = 5 \implies \mu y = \frac{5}{2} \end{equation*}
    Como \(\mu x = -1\text{,}\) vemos que \(\mu \neq 0\text{.}\) Desse modo, podemos expressar \(x\) e \(y\) em termos de \(\mu\text{:}\)
    🔗
    \begin{equation*} x = -\frac{1}{\mu} \quad \text{e} \quad y = \frac{5}{2\mu} \end{equation*}
    Substituímos estas expressões na Equação 5 (cilindro):
    🔗
    \begin{equation*} \left(-\frac{1}{\mu}\right)^2 + \left(\frac{5}{2\mu}\right)^2 = 1 \implies \frac{1}{\mu^2} + \frac{25}{4\mu^2} = 1 \end{equation*}
    \begin{equation*} \frac{29}{4\mu^2} = 1 \implies \mu^2 = \frac{29}{4} \implies \mu = \pm \frac{\sqrt{29}}{2} \end{equation*}
    Temos duas situações para analisar dependendo do sinal de \(\mu\text{:}\)
    🔗
    • Se \(\mu = \frac{\sqrt{29}}{2}\text{:}\)
      🔗
      \begin{equation*} x = -\frac{2}{\sqrt{29}} \quad \text{e} \quad y = \frac{5}{\sqrt{29}} \end{equation*}
      Substituímos na Equação 4 para achar \(z\text{:}\)
      🔗
      \begin{equation*} z = 1 - x + y = 1 - \left(-\frac{2}{\sqrt{29}}\right) + \frac{5}{\sqrt{29}} = 1 + \frac{7}{\sqrt{29}} \end{equation*}
      Obtemos o ponto crítico \(P_1 = \left(-\frac{2}{\sqrt{29}}, \frac{5}{\sqrt{29}}, 1 + \frac{7}{\sqrt{29}}\right)\text{.}\)
      🔗
      🔗
    • Se \(\mu = -\frac{\sqrt{29}}{2}\text{:}\)
      🔗
      \begin{equation*} x = \frac{2}{\sqrt{29}} \quad \text{e} \quad y = -\frac{5}{\sqrt{29}} \end{equation*}
      Substituímos na Equação 4 para achar \(z\text{:}\)
      🔗
      \begin{equation*} z = 1 - x + y = 1 - \frac{2}{\sqrt{29}} + \left(-\frac{5}{\sqrt{29}}\right) = 1 - \frac{7}{\sqrt{29}} \end{equation*}
      Obtemos o ponto crítico \(P_2 = \left(\frac{2}{\sqrt{29}}, -\frac{5}{\sqrt{29}}, 1 - \frac{7}{\sqrt{29}}\right)\text{.}\)
      🔗
      🔗
    Agora calculamos o valor da função objetivo \(f(x, y, z) = x + 2y + 3z\) em cada ponto crítico:
    🔗
    \begin{equation*} f(P_1) = -\frac{2}{\sqrt{29}} + 2\left(\frac{5}{\sqrt{29}}\right) + 3\left(1 + \frac{7}{\sqrt{29}}\right) = 3 + \frac{-2 + 10 + 21}{\sqrt{29}} = 3 + \frac{29}{\sqrt{29}} = 3 + \sqrt{29} \approx 8,39 \end{equation*}
    \begin{equation*} f(P_2) = \frac{2}{\sqrt{29}} + 2\left(-\frac{5}{\sqrt{29}}\right) + 3\left(1 - \frac{7}{\sqrt{29}}\right) = 3 + \frac{2 - 10 - 21}{\sqrt{29}} = 3 - \frac{29}{\sqrt{29}} = 3 - \sqrt{29} \approx -2,39 \end{equation*}
    Consequentemente, o valor máximo absoluto da função sobre a curva de interseção é \(3 + \sqrt{29}\) e ocorre em \(P_1\text{,}\) enquanto o valor mínimo absoluto é \(3 - \sqrt{29}\) e ocorre em \(P_2\text{.}\)
    🔗
    🔗

    Exemplo 1.9. Extremos em Curva de Interseção de Paraboloide e Plano.

    A curva de interseção do paraboloide \(z = x^2 + y^2\) com o plano \(x + y + 2z = 4\) é uma elipse. Determine os pontos nesta elipse que estão mais próximo e mais distante da origem.
    🔗
    Solução.
    Queremos encontrar os extremos da distância de um ponto \((x,y,z)\) na elipse até a origem. Algebricamente, é mais simples otimizar o quadrado da distância:
    🔗
    \begin{equation*} f(x, y, z) = x^2 + y^2 + z^2 \end{equation*}
    sujeito às restrições:
    🔗
    \begin{equation*} g(x, y, z) = x^2 + y^2 - z = 0 \quad \text{e} \quad h(x, y, z) = x + y + 2z = 4 \end{equation*}
    Os gradientes são:
    🔗
    \begin{equation*} \nabla f = \langle 2x, 2y, 2z \rangle, \quad \nabla g = \langle 2x, 2y, -1 \rangle, \quad \nabla h = \langle 1, 1, 2 \rangle \end{equation*}
    O sistema de equações de Lagrange \(\nabla f = \lambda \nabla g + \mu \nabla h\) se escreve em componentes como:
    🔗
    \begin{align*} 2x \amp = 2\lambda x + \mu \implies 2x(1 - \lambda) = \mu \quad \text{(Equação 1)}\\ 2y \amp = 2\lambda y + \mu \implies 2y(1 - \lambda) = \mu \quad \text{(Equação 2)}\\ 2z \amp = -\lambda + 2\mu \quad \text{(Equação 3)}\\ z \amp = x^2 + y^2 \quad \text{(Equação 4)}\\ x + y + 2z \amp = 4 \quad \text{(Equação 5)} \end{align*}
    Subtraindo a Equação 2 da Equação 1, obtemos:
    🔗
    \begin{equation*} 2x(1-\lambda) - 2y(1-\lambda) = 0 \implies 2(x - y)(1 - \lambda) = 0 \end{equation*}
    Isso nos dá dois casos a considerar:
    🔗
    • Se \(\lambda = 1\text{:}\) da Equação 1 concluímos que \(\mu = 0\text{.}\) Substituindo \(\lambda = 1\) e \(\mu = 0\) na Equação 3, temos \(2z = -1 \implies z = -1/2\text{.}\) No entanto, a Equação 4 exige \(z = x^2 + y^2 \ge 0\text{,}\) gerando uma contradição. Logo, não há solução para este caso.
      🔗
      🔗
    • Se \(x = y\text{:}\) substituímos esta relação nas Equações 4 e 5. Da Equação 4, temos \(z = 2x^2\text{.}\) Substituindo isso e \(y = x\) na Equação 5:
      🔗
      \begin{equation*} x + x + 2(2x^2) = 4 \implies 4x^2 + 2x - 4 = 0 \implies 2x^2 + x - 2 = 0 \end{equation*}
      Resolvendo a equação de segundo grau pela fórmula quadrática:
      🔗
      \begin{equation*} x = \frac{-1 \pm \sqrt{1^2 - 4(2)(-2)}}{2(2)} = \frac{-1 \pm \sqrt{17}}{4} \end{equation*}
      Como \(x = y\text{,}\) temos os seguintes pontos críticos:
      🔗
      • Para \(x_1 = y_1 = \frac{-1 + \sqrt{17}}{4} \approx 0,78\text{,}\) temos \(z_1 = 2 - x_1 = \frac{9 - \sqrt{17}}{4} \approx 1,22\text{.}\)
        🔗
        A distância quadrática à origem é \(f(P_1) = 2x_1^2 + z_1^2 \approx 2(0,78)^2 + (1,22)^2 \approx 2,70\) (distância de \(\approx 1,64\)).
        🔗
        🔗
      • Para \(x_2 = y_2 = \frac{-1 - \sqrt{17}}{4} \approx -1,28\text{,}\) temos \(z_2 = 2 - x_2 = \frac{9 + \sqrt{17}}{4} \approx 3,28\text{.}\)
        🔗
        A distância quadrática à origem é \(f(P_2) = 2x_2^2 + z_2^2 \approx 2(-1,28)^2 + (3,28)^2 \approx 14,04\) (distância de \(\approx 3,75\)).
        🔗
        🔗
      🔗
    Comparando os valores, concluímos que o ponto na elipse mais próximo da origem é \(\left(\frac{-1 + \sqrt{17}}{4}, \frac{-1 + \sqrt{17}}{4}, \frac{9 - \sqrt{17}}{4}\right)\) e o ponto mais distante é \(\left(\frac{-1 - \sqrt{17}}{4}, \frac{-1 - \sqrt{17}}{4}, \frac{9 + \sqrt{17}}{4}\right)\text{.}\)
